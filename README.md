# Tic-Tac-Toe Game

A C++ Object-Oriented Programming project that implements a console-based Tic-Tac-Toe game.

## Game Modes
- Player vs Player
- Player vs Computer (Easy)
- Player vs Computer (Hard)

## AI
- Easy AI selects a random valid move.
- Hard AI uses the Minimax algorithm to choose the best possible move.

## Main Classes
- Board
- Player
- HumanPlayer
- AIPlayer
- Game

## How to Run
Compile and run the `final.cpp` file using a C++ compiler.
